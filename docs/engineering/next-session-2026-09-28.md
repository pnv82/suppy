## Decisions that may merit review

- **Launch naming is offline and explicitly confirmed.** Automatic approval review rejected sending precise launch coordinates to a live geographic provider without specific consent. The implemented alternative ranks nearby athlete-confirmed starts and six historical Mission Bay beach references. The public references come from [City of San Diego, Mission Bay report, Table 2-4](https://www.sandiego.gov/sites/default/files/mbayfinal04.pdf#page=45), dated 2004. These are approximate beach-monitoring points, not surveyed launch locations or current access guidance. Catalog expansion remains deferred. Missing reliable start GPS or a nearby candidate preserves the source-location fallback; finish points never determine names. Suggestions are available in Edit and require Save.
- **Change arrows describe numbers, not improvement.** Compare each value with the immediately preceding three sessions under the same metric scope. All three values and a positive baseline must exist; show an arrow only when the absolute change exceeds 5%. Green means numerically higher, including HR and cadence. Missing sessions are not silently skipped. Whole-session maximum remains independent of the best-20-minute comparison scope.
- **Recalculate uses stored full telemetry.** It refreshes deterministic derived evidence without decoding or rewriting original FIT bytes, source summaries or athlete context. It is not a re-import or a retrospective repair of source data.
- **Goals are explicit tenant-wide targets.** Support maximum/average/best-5/10/20 speed and longest continuous time above a chosen cadence threshold. Targets use SI storage and dashed lines on matching Home charts. Cadence duration requires supported edges with both endpoints above the threshold; pauses, gaps and missing cadence split the effort. No automatic achievement or coaching interpretation is inferred. Goal changes invalidate external summaries through session revisions.
- **External summaries use a small versioned contract.** Store highlight, summary, model, evidence references and input revision separately from measured evidence. They remain unreviewed interpretations and become stale after relevant edits. Full typed analysis-envelope ingestion is still deferred. A header disclosure avoids adding permanent vertical space.
- **Layout and compatibility choices stay bounded.** Navigation labels appear at 1400 px and above. Chart Enter pins a selection; Shift-click or Shift-Enter extends it; Annotate opens the editor. Existing operator environment variables and tunnel profile names remain valid despite the Suppy branding. The MCP resource URI changed to `ui://suppy/dashboard.html`, so connected hosts need refreshed metadata.
